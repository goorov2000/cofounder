# 0014. Открываемые исторические реплики ответа

Дата: 15.11.2026. Статус: принято.

Ответ D16 цитировал прежнее требование, но не позволял открыть исходную реплику. Сервер добавляет `historySources` после декодирования ответа: только буквальные цитаты из видимого ответа/черновика, совпавшие с полным неизменяемым снимком `coreContext.sourceMessages` этого проекта. Текущий вопрос исключён. Модельное поле с таким именем всегда заменяется серверным результатом. Неоднозначные совпадения сохраняются все и явно обозначаются в интерфейсе.

Это навигация по происхождению текста, не проверка смысла вывода или авторства фразы в самом ответе. Снимок содержит настоящие роль, этап, поколение, ID, версию, дату и полный текст. Валидатор проверяет весь производный набор; существующий предел512KiB применяется после добавления снимков, без усечения оригиналов. Нового платного вызова нет; метаданные прежнего ответа не добавляются в следующий модельный prompt.

Панель «Источники» содержит ссылки на полный исходный текст, раскрывает соответствующую карточку, переводит фокус и прокручивает внутри диалога. Этап и draft сохраняются. React отображает оригинал как текст. Anchor строится при отображении; импорт переназначает вложенный projectId в reply, сохраняя финансовый request неизменным. Поэтому просмотр работает после импорта и сброса исходного чата.

Проверки: provenance/подделки/неоднозначность/размер/schema ошибки/import/reset; keyboard navigation, уникальные targets, полный original и escaping; браузер в обеих темах при1440×844,1280×720,390×844. Живое D16 и полный контроль фиксируются отдельно в `.repair/2026-11-15/`.
