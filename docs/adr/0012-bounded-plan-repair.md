# ADR0012 — Исправление завершённого неверного плана

15.11.2026. Цикл2 обычного ремонта. Дополняет ADR0011; историческая сборка не переоценивается.

В фиксированном контрольном наборе планировщик D13 дважды завершил оплаченный ответ невалидным JSON: два одинаковых объекта и, отдельно, несовместимые объекты с посторонним текстом. Нельзя выбирать первый/последний вариант или склеивать query догадкой.

Разрешён ровно один plan-repair после completed с корректным usage и невалидным планом. Он заново выбирает одно действие/query из исходного контекста по той же strict-схеме. Предыдущий raw — недоверенные данные, не инструкции. JSON, shape и query length имеют отдельные safe rule codes; validation обоих исходов сохраняется. Сеть, отказ, incomplete и неверный usage не повторяются. Повторный неверный план завершает запрос ошибкой, до поиска и изменения памяти.

Полный reserve заранее включает plan + plan-repair + bounded search + generate + generate-repair: максимум5 paid child calls. Hosted search по-прежнему ограничен3tool calls и6страницами. Для вложенного raw учитывается6×256KiB, полный исходный контекст/инструкции/schema и1024outputtokens планировщика. originalInput вкладывается объектом, не повторно экранированной строкой. Одна генерация результата сохраняет прежний maxOutputTokens, совокупный output guard учитывает оба plan и оба generate. Все операции — тот же ledger, cap15total. plan-repair не повторяет уже завершённый поиск.

Связанный ремонт: validator передаёт до10 независимых path/rule нарушений без значений источников. Одна generate-repair исправляет relatedIssues целиком; не реконструирует URL и не удаляет claims программно. Явное утверждение точного названия страницы проверяется по server-owned metadata. Краткая ссылка на бренд не обещает полного заголовка; числовая льгота title остаётся только для точного совпадения. Quote/URL match не доказывают универсального смыслового соответствия.

Проверки: исторические malformed-plans и K04/D14 raw,5paidchildren/reserve/cache, HTTP+SSE reset/replay, атомарность/source guards. Полная живая повторная приёмка проводится отдельно на новом коммите и сохраняет все первоначальные провалы.
