## Контекст
для произвольной идеи нужен настоящий AI, а ключ не должен попадать посетителю; G01 закрепляет выбор OpenAI вместо прежнего списка кандидатов.

## Решение
Обращаемся к OpenAI Responses API только через сервер. Сервер выбирает модель и строит инструкции; принимает пользовательский текст как данные, проверяет структурированный ответ и различает ошибки. Используем store:false, без инструментов и автоматических повторов SDK.

## Почему
Альтернатива DeepSeek уступает прямому выбору пользователя «Давай OpenAI сделаем»; сравнительная оценка провайдеров источниками не подтверждена. Заготовленные реплики отклоняем как замену основному AI-режиму: они не обслуживают произвольную идею. SSE не требуется, поскольку завершённого ответа достаточно и частичный JSON не нужен интерфейсу.

## Последствия
Отсутствие подключения показывается явно. Локальная работа и экспорт доступны без AI. Поздние G03/T07 заменяют начальное состояние без ключа: разрешена проверка до $5, выбранный gpt-6-luna прошёл 13 запросов через приложение; это не доказывает качество всех будущих диалогов. Публичный HTTPS остаётся отложенным.
