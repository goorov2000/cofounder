# ADR0021 — локальная демонстрация вместо публичного сайта

Уточнение16.11.2026: последовательность полных генераций и правило непродуктивных циклов заменены [ADR0022](0022-collect-before-compose.md). Локальная конфигурация, транспорт и финансовый ledger сохраняются.

16.11.2026. Пользователь: «давай поменяем ограничения: публичного сайта решил не делать, буду показывать через локал на демонстрации экрана в зуме».

## Причина

Предел трёх циклов возвращал частичный результат, хотя оценщик уже указал доступную следующую проверку. Интерфейс требовал отдельное сообщение для продолжения. Ограничения для посетителей публичного сайта потеряли основание после отмены размещения. Денежный потолок установки пользователь не повышал.

## Решение

- По умолчанию отключены rate-ограничения сессии/IP, выдачи новых сессий и глобальной параллельности. Нулевые значения admission означают отсутствие соответствующего ограничения. Положительные программные значения по-прежнему применяются, в том числе в проверках. Один активный ход на сессию сохраняет порядок памяти и не допускает конфликтующих ответов из вкладок.
- Фиксированного предела числа исследовательских циклов нет. `nextStep=research` исполняется в том же запросе с прежней пользовательской репликой и атомарным применением только итогового ответа. Вопрос о личном решении, явная остановка, запрет поиска, ошибка или недоступность источников возвращают управление по прежним правилам.
- Задача получает до15минут, один цикл до180секунд, оценщик до60секунд в оставшемся времени цикла. HTTP, pendingUntil и provider используют согласованные сроки. Это конечная защита зависшей задачи, не обещание закрыть любой критерий.
- Новое сведение — новый URL/contentHash действительно прочитанной страницы; новая запись того же чтения или новый текст запроса прогрессом не считаются. Улучшение покрытия — рост лучшего достигнутого состояния критерия missing/partial/covered. Три последовательных цикла без новых сведений и без улучшения критериев останавливают повторяющуюся работу с явным partial. Поиск с тем же query дополнительно блокируется до оплаты, как ранее.
- Общий разрешённый потолок$15, накопленный расход, поэтапные атомарные резервирования, финансовые tombstones и неизвестный расход сохраняются. В исследовательском loop прямой provider также проверяет сумму уже оплаченного/неопределённого и нового резерва до начала шага. Рабочий HTTP дополнительно проверяет оставшийся бюджет установки в прежнем SQLite ledger. `estimateMaxCost` при включённом оценщике теперь учитывает весь бюджет задачи, а не три цикла; программные проверочные admission не должны считать его резервом обычного HTTP.
- Основной ответ по умолчанию16384токена; явное меньшее значение сохраняется, настраиваемый максимум32768. Это запас длины, а не команда делать каждый ответ длиннее. Незавершённый ответ всё ещё не применяется и не повторяется автоматически.
- UTF-8 границы: запрос1MiB, исходный JSON модели256KiB, проверенный ответ2MiB, клиентский JSON/SSE-кадр4MiB, весь поток8MiB. Диагностика до4096операций. Источники/критический контекст не обрезаются. Ограничения одного поиска, чтения страницы и хранилища браузера сохранены.
- Из интерфейса убрано универсальное указание отправлять отдельное сообщение при любом partial. Конкретная причина остановки и уже полученный результат остаются видимыми.

## Размещение и совместимость

Публичный сервер/домен/HTTPS отменены пользователем. Локальный origin, существующий ключ, выбранные модели, DATA_DIR, проекты и ledger сохраняются. Host по умолчанию127.0.0.1; Docker/Caddy остаются исторической подготовкой, не обязательной работой. Новых платных запросов для проверки этой правки не требуется.

Пороги ADR0010/0020 и прежнее требование публичного размещения заменены этим решением. Защиты происхождения источников, цитат, памяти, origin и повторной оплаты не отменяются.

## Проверка

Сценарии: четвёртый цикл завершает тему в одном HTTP, восемь циклов с48страницами/82операциями помещаются и сохраняются, повтор из ledger бесплатен; полезные новые чтения продолжают работу, повтор одинаковых чтений останавливается; прежние бюджет/abort/unknown guards проходят. Локальная серия40сообщений и20подключений не попадает в публичные rate-ограничения; четыре разные сессии работают параллельно, второй ход занятой сессии отклоняется.

Итог запуска проверок фиксируется в local-demo-validation.md (локальный материал). Синтетические проверки не доказывают полноту текущего живого исследования пользователя.
