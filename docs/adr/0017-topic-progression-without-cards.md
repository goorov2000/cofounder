# Завершение темы без карточки

Решение пользователя16.11.2026: карточка идеи слишком длинная и не нужна. Данные остаются в контексте. При100% бот коротко сообщает, что в целом понял тему; следующая тема доступна, переход добровольный. Можно продолжать обсуждение. Уточнение: свободное переключение относится только к уже разблокированным темам.

В рабочем чате нет StageResult, отдельного редактора и обязательного сохранения. TopicCompletion показывает короткую реплику и кнопку перехода. Дополнительное сообщение пользователя обрабатывается в прежней теме. Материал, явно запрошенный пользователем, модель показывает непосредственно в message; artifactDraft служит внутренним контекстом.

Следующая тема маршрута открывается после полного актуального покрытия предыдущей, если отдельная проверка не вернула замечания или недоступность. Для открытия не нужны artifactDraft и artifact. Готовность оценщика также не требует карточки. Переход не происходит автоматически.

Project.unlockedStages фиксирует уже открытые темы. ApplyAnswer расширяет этот список после успешного применения ответа; переход через Application тоже фиксирует доступ. Последующие уточнения, устаревшая оценка и перезапуск предыдущего чата не отбирают уже полученный доступ. Новая тема дальше по маршруту требует собственного полного покрытия. Инструменты сохраняют предметные зависимости. Старые сохранённые материалы и ранее доступные темы совместимы с новым сценарием; их наличие не превращается в выдуманную оценку100%.

Внутренние формулировки других тем передаются в context.artifacts с provenance=assistant_proposal, без повышения до пользовательских или проверенных фактов. Текущая формулировка передаётся в currentDraft без дублирования. Ответ без нового artifactDraft сохраняет предыдущую формулировку в proposal. При перезапуске действуют прежние границы контекста и поколений. Старые artifact остаются в хранилище и JSON-экспорте; карточки для них в чате не восстанавливаются.

Презентация и Markdown-экспорт используют внутренний контекст, если старого сохранённого материала нет. Предложения модели, гипотезы и неизвестное сохраняют явные оговорки; новые карточки для экспорта создавать не требуется.

ModuleState.completedAt фиксирует достигнутое полное покрытие для накопительного маршрута. Он не подменяет свежую оценку критериев: после уточнений текущая проработка может уменьшиться, а пройденные темы и их доступ сохраняются. Перезапуск темы очищает её отметку прохождения.
