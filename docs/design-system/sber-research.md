# Как различаются интерфейсы и дизайн-системы Сбера

Исследование 14.11.2026 по запросу Григория. Цель — выбрать цельную основу CoFounder и дать агенту проверяемые правила, вместо приблизительного «сделай в стиле Сбера».

**Вывод:** единственного набора зелёных кнопок для всех продуктов нет. Подтверждены отдельный Triplex Next и семейство Plasma/SDDS с продуктовыми темами. Для текущей версии CoFounder сохранена основа СберБизнеса: спокойные непрозрачные панели, бирюзовые действия, формы и широкая рабочая область. Светлая и тёмная темы используют одинаковую структуру. Это наш выбор по задаче, а не официальная рекомендация Сбера.

## Основания и степень уверенности

| Источник | Что действительно проверено | Чего из этого не следует |
|---|---|---|
| Два локальных HTML СберБизнеса | DOM, CSS, вычисленные переменные активных тем в Chromium; сохранена версия токенов `0-15-0` | Полная клиентская библиотека и все сценарии банка не восстановлены |
| Пять скриншотов пользователя | Светлая desktop-компоновка, таблица и пустое состояние; мобильная пара; тёмный СберБизнес | По изображению нельзя установить внутренний стек или точные размеры в CSS px |
| Triplex Next, организация SberBusiness | README, ThemeProvider, package.json, лицензия | Текущий репозиторий не равен версии из сохранённого HTML |
| Plasma/SDDS, salute-developers | README, пять пар CSS-тем, SHA каждого файла, документация | Название B2C не доказывает, что СберБанк Онлайн использует эту библиотеку |
| Публичные страницы | В браузере открыты Developers, Jazz Platform, каталог Plasma, Theme Builder, документация и оболочка Storybook Giga | Рекламная страница продукта не является полным описанием его рабочего приложения |

Код извлекался из первичных источников. Точные значения и SHA — в theme-comparison.json (локальный материал). Локальные значения — в source-tokens.json (локальный материал). Скриншоты публичных страниц и наблюдения сохранены в `research/`; пользовательские финансовые данные в них не переносились.

## СберБизнес / Triplex

В пользовательских HTML присутствуют семейства `triplex` и `triplex-next`. Видимые признаки: нейтральный холодный фон, крупные панели, бирюзовые действия, линейные иконки, компактные кнопки, таблица с отдельной строкой пояснения. Тёмный скриншот уточняет чёрный внешний фон и графитовые панели; он не похож на простое затемнение белого интерфейса.

Официальный [Triplex Next](https://github.com/SberBusiness/triplex-next) предоставляет библиотеку компонентов. [ThemeProvider](https://github.com/SberBusiness/triplex-next/blob/main/src/components/ThemeProvider/ThemeProvider-ai.md) связывает глобальные и компонентные токены, поддерживает LIGHT/DARK и локальное переопределение. Суффикс версии в CSS-переменной генерируется библиотекой: фиксировать такие имена как публичный API собственного приложения не следует. Поэтому CoFounder использует короткие собственные семантические роли.

Из этого семейства для CoFounder взяты организация поверхностей, спокойная плотность, оформление действий, таблиц и статусов. Компоновка сохранена по пользовательским UI01–UI08: чат в центре, маршрут справа. Полный банковский dashboard с рекламными плитками здесь не нужен.

## Мобильный СберБанк Онлайн

Первые два скриншота последнего сообщения — светлый и тёмный мобильные экраны с «Кошельком», переводами, историей и нижней навигацией. Эта структура соответствует описанию на [официальной странице приложения](https://www.sberbank.ru/ru/person/sberbank-online).

**Наблюдения по скриншотам:** зелёные основные действия, округлые группы, крупные суммы и заголовки, большие области касания. Светлая версия имеет белые карточки; тёмная показывает полупрозрачные карточки в верхней зоне поверх цветного фона и непрозрачные блоки операций ниже. Поэтому даже внутри одного экрана используются разные правила поверхностей.

Фон может быть персонализирован: возможность выбрать собственную картинку или коллекцию описана в [официальном материале об обновлении 2024 года](https://www.sberbank.ru/ru/person/blog/chto-novogo-v-sberbank-online). Следовательно, конкретный зелёно-бирюзовый фон скриншота нельзя объявлять обязательным цветом всей системы.

Для CoFounder полезны ясная группировка и крупные touch-области. Стеклянные панели поверх пёстрой подложки в длинном рабочем разговоре не применены. Точная внутренняя дизайн-система мобильного банка по этим материалам не установлена; привязка к SDDS Service или Plasma B2C была бы предположением.

## Plasma / SDDS: семейство продуктовых тем

[Официальный репозиторий SDDS (Plasma)](https://github.com/salute-developers/plasma) прямо описывает продуктовые вертикали: общие компоненты сочетаются с отдельными темами и конфигурациями. В списке есть Web, B2C, Giga, Service, FinAI, Platform-AI и другие. Это объясняет, почему родственные интерфейсы могут иметь разный акцент и характер.

Ниже **токен акцентного текста**, а не «весь фирменный цвет продукта». Источник — CSS текущей ветки `dev`, прочитан 14.11.2026. Альфа `FF` для непрозрачных значений Giga в таблице опущена; исходная запись сохранена в JSON.

Различие роли важно практически. Например, в Service светлый `text-accent` — `#108E26`, а `surface-accent` — `#1A9E32`. В Malachite это `#0C8688` и `#0C9597`. Один hex для текста, кнопки и её подписи разрушил бы эту структуру. Документация [SDDS Service](https://plasma.sberdevices.ru/sdds-serv/) также явно перечисляет обе версии акцента и пары светлой/тёмной тем.

У Giga тёмный акцентный текст белый; цветовое разнообразие иллюстраций или логотипа не следует переносить на каждую кнопку. [Документация Giga](https://plasma.sberdevices.ru/giga/) даёт отдельные тему, типографику и компоненты. Фактическую текущую авторизованную страницу gigachat.ru исследовать не удалось, поэтому значения выше относятся к опубликованной библиотеке, не к гарантированному виду всех экранов сервиса.

### Документация для агента

В [документации MCP для Giga](https://plasma.sberdevices.ru/giga/how-to-mcp/) предусмотрена выдача списка компонентов, props, токенов, примеров и руководств. Это напрямую соответствует задаче пользователя: агент должен выбирать из известной системы и проверять контракт компонента. Доступен и [Theme Builder](https://plasma.sberdevices.ru/plasma-theme-builder/) с отдельными схемами цвета, типографики, радиусов, отступов и теней.

Для нашего небольшого прототипа такой контракт реализован локально: `tokens.css`, библиотека примеров, переиспользуемые компоненты и agent-guide. Внешний MCP не устанавливался и конфигурация агентского окружения не менялась. При переходе на готовую вертикаль его имеет смысл подключать вместе с выбранной библиотекой, а не добавлять документацию сразу для всех несовместимых тем.

У [SDDS Service AI Kit](https://plasma.sberdevices.ru/sdds-serv/ai/answer/) есть отдельные элементы для AI-интерфейсов. Это дополнительный источник паттернов для следующего этапа чата; наличие библиотеки не заменяет правила сохранения, происхождения фактов и текущую бизнес-логику CoFounder.

Публичные страницы банка в этом браузере возвращали ошибку сертификата/служебный экран, выбранный URL СберБизнеса — 404. gigachat.ru завершился таймаутом; jazz.sber.ru — ошибкой сертификата; SberDevices перенаправил на служебный SSO-экран. Эти попытки не считаются просмотренными продуктовыми интерфейсами. Контекст банка подтверждён официальным текстом страницы через поиск, а визуальная основа — предоставленными HTML и скриншотами. Вход в аккаунты и банковские операции не выполнялись.

## Что принято для CoFounder

1. **Основа Triplex/СберБизнес.** Подходит к задаче постоянной работы: разговор, формы, результаты, расчёты и маршрут. Выбор обусловлен сценарием и явно переданным референсом.
2. **Одна семантическая система, две темы.** Брендовый акцент, ссылка, фон действия и его подпись имеют разные роли. Подтверждённые значения сохраняются там, где они подходят; коррекции контраста перечислены в [README](README.md).
3. **Мобильные приёмы — по назначению.** Крупные области касания и группировка полезны. Персональные фоновые картинки, банковские карты и стеклянная область кошелька в рабочий чат не переносятся.
4. **Готовые паттерны Giga/SDDS — для изучения чата.** Схемы ответа, обратной связи и ввода можно оценивать отдельно, сохраняя основную тему проекта.
5. **Агент получает исполняемый пример.** Один документ сам по себе недостаточен: правила подкреплены компонентами, переключателем темы и браузерными проверками.

Библиотеки автоматически не установлены. У [Triplex Next package.json](https://github.com/SberBusiness/triplex-next/blob/main/package.json), прочитанного в ходе исследования, peer React `^18.0.0`; у текущего прототипа React 19. Кроме того, [лицензия Triplex](https://github.com/SberBusiness/triplex-next/blob/main/LICENSE.txt) называется Sber Public License at-nc-sa v.2 — нельзя считать поставку MIT по умолчанию. Исходный код компонентов, брендовые изображения и шрифты из внешнего репозитория в нашу сборку не копировались. Используются собственные компоненты, имеющиеся Onest и Lucide.

На этапе исследования14.11 новые темы «Plasma Web», «Giga», «зелёный Сбер» в настройку CoFounder не добавлялись. По новому прямому запросу16.11 добавлены пять цветовых адаптаций с независимым светлым/тёмным режимом; актуальное решение и границы — в [README](README.md). Геометрия и компоненты общие. Это заменяет обязательность палитры СберБизнеса, не результаты исходного исследования.
