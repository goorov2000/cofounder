# Анимации CoFounder

Принято по запросу пользователя16.11.2026. Движение объясняет изменение состояния и помогает проследить связь элементов. Оно остаётся спокойным: без пружин, отскоков, декоративных пролётов и задержки действия ради эффекта. Светлая и тёмная темы используют одинаковые правила.

## Общая шкала

Единственный источник времени и кривых — `src/design-system/tokens.css`. CSS использует переменные напрямую, Web Animations — `motionTiming` и `animateMotion` из `motion.ts`. Числовые длительности в компонентах не задаются. Старый `--ds-duration` — совместимый alias быстрого отклика.

| Роль | Токен | Время | Применение |
|---|---|---:|---|
| Отклик | `--ds-motion-feedback` | 140 мс | Цвет кнопки, hover, нажатие |
| Появление | `--ds-motion-enter` | 180 мс | Появление содержимого, новая подпись ожидания |
| Исчезновение | `--ds-motion-exit` | 140 мс | Уход содержимого при закрытии |
| Компоновка | `--ds-motion-layout` | 280 мс | Высота раздела, поворот стрелки |
| Перемещение | `--ds-motion-journey` | 420 мс | Название этапа из центра в шапку |
| Спокойное ожидание | `--ds-motion-ambient` | 1600 мс | Цикл точек реального ожидания ответа |
| Рабочий индикатор | `--ds-motion-cycle` | 1000 мс | Вращение индикатора занятой кнопки |
| Сдвиг точек | `--ds-motion-stagger` | 180 мс | Смещение фаз точек одного индикатора |

Обычные переходы используют `--ds-motion-ease: cubic-bezier(.2, 0, 0, 1)`. Длинное перемещение — `--ds-motion-ease-journey: cubic-bezier(.22, 1, .36, 1)`. Ожидание — `--ds-motion-ease-ambient: ease-in-out`; равномерное вращение остаётся linear. Новые роли добавляются в общую шкалу с объяснением.

## Поведение

- Состояние, запрос и ARIA обновляются сразу. Анимация сопровождает действие, не задерживает отправку и не блокирует следующие действия. Одновременные изменения одного события, например заголовок и панель после первой отправки, стартуют вместе, без дополнительного таймера.
- Первый экран текущего этапа открывает «Маршрут проекта». Первая отправка, в том числе стартовой кнопкой, переключает панель на «Проработку темы». Дальнейшие ответы, поток и обновления оценки не меняют ручной выбор раздела. Перезапуск возвращает маршрут; при открытии уже начатого чата или восстановлении страницы проработка сразу открыта. Данные предыдущих этапов сами по себе не означают, что разговор текущего этапа начат.
- В панели одновременно выбран максимум один раздел. `Disclosure` плавно изменяет естественную высоту без фиксированного max-height. Закрываемое содержимое сразу получает inert и aria-hidden: в него нельзя попасть клавишей Tab или прочитать как открытый раздел, пока оно ещё исчезает. Фокус кнопки переключения остаётся на месте. Стрелка использует ту же длительность, что и раздел.
- Повторное нажатие разворачивает текущий CSS-переход, без очереди таймеров. Текст и данные внутри уже открытого раздела обновляются обычным способом: новые токены ответа, числа и уточнения не запускают анимацию всего чата. Положение чтения и существующие правила следования за ответом сохраняются; отдельная прокрутка панели не добавляется.
- Web Animations имеют завершение и отмену с одинаковой очисткой. Временный заголовок скрыт от скринридера. Переключение этапа, размонтирование или resize удаляют временную копию; повторное открытие переписки не повторяет перенос.
- При prefers-reduced-motion:reduce все CSS-переходы, циклические анимации и плавная прокрутка отключены. JavaScript не начинает движение; включение настройки во время переноса отменяет его и сразу показывает конечный заголовок. Содержание, фокус, доступ к разделам и функциональность сохраняются.
- Повторяющееся движение допускается для настоящего ожидания операции. Оно не сообщает о несуществующем поиске, прогрессе или выполнении этапов. Скрытые и доступные состояния должны оставаться понятными без движения.

## Использование

Для раскрытия — общий `Disclosure`, кнопка с aria-expanded и aria-controls. Общие Button и IconButton уже используют отклик140мс. Для переноса заголовка — `useStageTitleTransition` с ролью journey; для другой обоснованной Web Animation — `animateMotion(element, frames, role, options)`. Длительность и easing он читает из тех же CSS-токенов и следит за reduced motion.

Интерактивный пример — `/design-system#motion`: первая отправка, следующий ответ, ручное переключение и возврат на первый экран без AI. Перенос названия показан в разделе «Первый экран этапа». Проверять обе темы, узкий экран, быстрые повторные нажатия, клавиатуру, черновик, общую прокрутку, восстановление и reduced motion.
