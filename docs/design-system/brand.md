## Favicon

`public/favicon.svg` — самостоятельная SVG-обёртка с оригинальным PNG внутри альфа-маски; это не векторная перерисовка. Фон полностью прозрачный, без квадрата или плашки. Знак занимает почти всю иконку, оставляя2единицы отступа на64. Рамка использует те же crop-координаты из brand.json. Установка favicon имеет новую версию URL, чтобы обновить прежнюю иконку из кеша.

Без React доступен бирюзовый вариант с адаптацией к светлому/тёмному браузеру. При запуске и смене палитры useTheme передаёт два цвета favicon в updateBrandFavicon; шаблон загружается один раз и переиспользуется, устаревшее завершение загрузки не заменяет более новый выбор. Полученный самостоятельный SVG устанавливается как data URI. `--ds-favicon-light` и `--ds-favicon-dark` в tokens.css соответствуют акцентам палитры, но применяются к светлому/тёмному окружению вкладки через prefers-color-scheme. Это позволяет ручной тёмной теме приложения не делать белый знак невидимым на светлой панели браузера. При сбое загрузки шаблона сохраняется статический favicon. Для обновления формы заново использовать присланный исходник, не рисовать приближение по памяти.

Воспроизводимость:

```sh
node scripts/build-brand-assets.mjs
node scripts/build-brand-assets.mjs --check
```
